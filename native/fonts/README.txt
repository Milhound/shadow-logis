InterVariable.ttf and InterVariable-Italic.ttf are unmodified upstream variable
fonts, copied from the Arch extra/inter-font 4.1-1 package. They include all font
weights used by the UI. OFL.txt contains the SIL Open Font License 1.1.

SHA-256:
4989b125924991b90d05b2d16e0e388c48f7d5bb8b30539bbf9c755278d0ccaf  InterVariable.ttf
d6f1f6a172d9e588438db9f986fd5cfad7b30f644374080a8a9d4d91e344586f  InterVariable-Italic.ttf

Both fonts and their license are compiled into the application. No download,
system-wide font installation or internet connection is required. The font
license can be read through Help > Inter font license. Shipping PDF renderers
retain their separate document fonts; form alignment is not based on the UI font.
